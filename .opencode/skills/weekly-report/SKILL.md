# Weekly Report SOP

1. Gather source metrics from approved local files and connected systems.
2. Use `templates/weekly-report.md` as the output structure.
3. Separate observed facts from estimates and flag missing data.
4. Run no external sends or production changes.
5. Return the completed draft for human review.
